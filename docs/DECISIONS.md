| 2026-09-27 | Ajout d'une règle CSS `@media (prefers-reduced-motion: reduce) { [data-reveal] { opacity: 1 !important; transform: none !important; } }` dans `globals.css`, en complément de `MotionConfig reducedMotion="user"`. | Vérifié (Playwright, `reducedMotion: "reduce"`) : la bibliothèque `motion` ne neutralise que les animations de position/transform (x, y, scale…) sous mouvements réduits, pas l'opacité (code source : `shouldReduceMotion && positionalKeys.has(key)`).
